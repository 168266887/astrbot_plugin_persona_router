# 人格分流（astrbot_plugin_persona_router）

**按发言人 QQ 号强制切换人格** —— 同一个群里，对主人用一副人格，对其他人用另一副。

AstrBot 原生的人格是**会话级**的：一个群只能挂一个人格。因此「群里某个人特殊对待」这件事，
靠人格文本里写 if-else 是做不到的 —— 模型根本看不到发言人的 QQ 号，只能凭感觉猜，
于是永远演第一个提到的人格。本插件在 `on_llm_request` 阶段按 `sender_id` 直接把人对应的
人格全文拼进 system prompt，属于**硬切换**，不依赖模型自己判断。

## 效果

```
发言人 168266887（主人）  → 拼接「猫娘」人格全文
发言人 3196204560（其他人）→ 拼接「贴吧鱼」人格全文
```

注入块位于 system prompt 最末尾（最高优先级），并声明覆盖上文任何人格描述。

## 配置

| 项 | 说明 |
|---|---|
| `master_qq` | 主人格对应的 QQ 号，填了才启用分流 |
| `master_persona` | 这个号使用的人格名（AstrBot「人格设定」里的名字） |
| `default_persona` | 其他所有人使用的人格名 |
| `group_ids` | 只在指定群生效，留空 = 所有会话（含私聊） |
| `max_chars` | 人格文本注入上限，默认 4000 |

人格文本从 AstrBot 的数据库（`data/data_v4.db` 的 `personas` 表）实时读取，
改人格后 **30 秒内**自动生效，无需重启。

## 注意

- 人格名必须和「人格设定」里的**完全一致**，否则插件会在日志里警告并跳过。
- 建议把 AstrBot 核心默认人格设成中立的 `default`，避免和插件注入的人格打架。
- 日志会打印每次路由结果，排查时直接看：
  ```
  [persona_router] 发言人 168266887（主人）→ 使用人格「猫娘」
  ```

## 安装

把整个目录放到 AstrBot 的 `data/plugins/` 下，重载插件即可。
